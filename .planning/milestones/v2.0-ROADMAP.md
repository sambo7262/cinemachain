## Milestone Goal

Expand CinemaChain beyond the game loop — fix all known v1 friction points, add Query Mode for direct movie discovery, richer session tools (save/compare), deeper MDBList data integration, watched-history view, and a cluster of UX/data-quality polish.

**Core Value Delivered:** The Movie Game now lives inside a complete media-companion app — users can chain-discover, search directly, save/shortlist for comparison, see watched history, and get IMDB+RT+Metacritic+Letterboxd scores on every movie.

## Milestone Summary

### Major Capabilities Added Over v1.0

1. **Query Mode** — search movies/actors, browse genre, request via Radarr without starting a game
2. **Save + Shortlist** — bookmark and compare 2–6 movies during gameplay
3. **Watched History** — first-party tile/grid view of every watched movie across sessions
4. **Multi-source ratings** — IMDB, RT, Metacritic, Letterboxd, MDB Average displayed everywhere
5. **TMDB suggestions** — recommendations filter, intersected with eligible actors
6. **Mobile redesign** — card-based eligible movies, mobile nav overflow fixes
7. **Settings hardening** — key masking, log scrubbing, encrypted DB storage, test-connection buttons
8. **Filmography freshness** — 14-day TTL self-heal + nightly force-refresh + manual button

### Notable Decisions

- **MDBList watched-sync abandoned** (Phase 14) — replaced with first-party Watched History
- **Synchronous on-demand TTL refresh** (Phase 22 D3) — chose latency tradeoff over stale-while-revalidate so active sessions see fresh data on the same click
- **Module-level `FILMOGRAPHY_TTL_DAYS` constant** (Phase 22 D2) — not a settings field; promotable later if needed
- **Git history squashed at v2.0 tag** (Phase 21) — clean two-commit history for public-facing repo
- **Suggested Movies feature removed entirely** (Phase 4.1, retroactive) — unreliable; replaced by TMDB-Recommendations (Phase 15)

### Known Tech Debt Carried to v2.1

- Two ad-hoc post-Phase-21 feature commits unattached to any phase (see above)
- `backend/app/routers/debug.py` exists as dead code (unreachable, not registered in main.py)
- `postgres` service in compose.yaml lacks explicit `networks:` declaration (implicit, works)
- Phase 22 `filmography_fetched_at` populated only for actors interacted with post-deploy; long-tail actors stay NULL until first encounter (by design — D1 no-backfill decision)

### Carried-Forward Concerns Resolved During v2.0

- ✅ RT scores — MDBList API integrated (Phase 13)
- ✅ pyarr currency — direct httpx RadarrClient implementation (carried over from v1)
- ✅ Plex webhook reliability — Plex entirely removed (manual Mark as Watched only)
